# Dynamic Singly Linked List in C

A simple C program demonstrating how to create, populate, and traverse a dynamic singly linked list using `malloc()`[cite: 1].

## Features
- Dynamic memory allocation for new nodes[cite: 1].
- Interactive prompt allowing users to enter custom data[cite: 1].
- Sequential traversal and printing of the linked list[cite: 1].

## Prerequisites
